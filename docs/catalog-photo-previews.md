# Catalog photograph previews

The storefront banner and six garment masters were created with the built-in image-generation tool. They are photorealistic demonstration images, rather than supplier photographs. The storefront and product page identify them as demo previews. Owner-uploaded photographs keep priority over these samples.

The garment generation brief excludes people, visible mannequins, hangers, logos, labels and text. The six original transparent files are retained without raster edits. The website uses each master’s transparency and fabric shading to display the catalog’s existing color palette. This avoids separate large image files for every size of the same color. Actual shade, fabric, fit and details still require store confirmation.

The banner prompt requested: “Create a premium photorealistic clothing storefront hero photograph, square composition. Exactly two unbranded plain cotton short-sleeve crew-neck T-shirts as clean ghost-mannequin cutouts arranged in a stylish floating flat-lay on a seamless warm pale cream (#fff3e6) studio background. One shirt is warm off-white and placed lower left, angled slightly counterclockwise; one shirt is rich dark garnet red (#621708), placed upper right, angled slightly clockwise. Both shirts fully visible with comfortable margins, realistic soft cotton weave, neatly stitched crew collars, subtle natural folds, tactile fabric, soft realistic studio shadows beneath them. No people, no mannequins visible, no hangers, no sketches, no illustrations, no logos, no letters, no labels, no badges or typography, no props. Accurate clothing photography, consistent elegant soft diffuse lighting. Composition should fit the right half of a white-and-garnet retail website hero with no text.”
